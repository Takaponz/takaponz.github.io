# takaponz.github.io

Takaponz の GitHub Pages ユーザーサイト。

## 役割

- `app-ads.txt` の配信（IAB Tech Lab 仕様準拠・AdMob 連携用）
- 公開アプリのインデックス
- 数直線スナイパーの紹介・サポート・プライバシーポリシー

## ファイル

- `app-ads.txt` — AdMob pub ID の所有証明
- `index.html` — 公開アプリ一覧
- `number-sniper/` — 数直線スナイパー公式ページ
- `number-sniper/support/` — サポート・問い合わせ窓口
- `number-sniper/privacy/` — プライバシーポリシー
- `assets/` — 共通スタイルと公開画像
- `tests/site_check.sh` — 公開ルートと必須リンクの検証

## 公開 URL

https://takaponz.github.io/

## 検証

```sh
sh tests/site_check.sh
```
